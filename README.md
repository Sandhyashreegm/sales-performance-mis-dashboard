# Sales Performance & MIS Dashboard

## Project Overview

This project demonstrates sales data cleaning, MIS reporting, KPI analysis, and dashboard creation using Microsoft Excel. It helps summarize sales performance and present business information in an easy-to-understand format.

## Objectives

- Clean and validate sales data.
- Prepare structured data for MIS reporting.
- Track important business KPIs.
- Analyze sales performance by category, city, and salesperson.
- Present insights through an interactive Excel dashboard.

## Tools Used

- Microsoft Excel
- Pivot Tables
- Excel Formulas
- Data Cleaning and Validation
- Charts and Dashboard Design

## Dataset

The project uses a sample sales dataset containing order details, product categories, locations, quantities, sales values, discounts, and salesperson information.

## Key Performance Indicators (KPIs)

- Total Orders
- Gross Sales
- Net Sales
- Estimated Profit
- Profit Margin
- Average Order Value (AOV)
- Monthly Sales Performance
- Category-wise Sales
- Salesperson Performance

## Project Workflow

1. Reviewed the raw sales data.
2. Cleaned and standardized data fields.
3. Checked for duplicate records and invalid quantities.
4. Prepared calculated columns and business KPIs.
5. Created an Excel dashboard for sales performance reporting.

## Files Included

- **Sales_Performance_MIS_Portfolio.xlsx** — Excel workbook containing the project data and dashboard.
- **Sales_Performance_Project_Report.pdf** — Project documentation, methodology, and limitations.

## Business Value

This project demonstrates how Excel can support recurring MIS reports, monitor business performance, identify sales trends, and communicate key metrics to stakeholders.

## Limitations

The dataset is for portfolio demonstration purposes. Estimated costs and profit figures are illustrative assumptions and should not be treated as actual business financial results.
